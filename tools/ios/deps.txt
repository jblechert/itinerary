# PDF import is deliberately removed on iOS: Poppler, which kitinerary uses to read PDF tickets, is GPL licensed,
# and distributing GPL code through Apple's App Store conflicts with the App Store terms. This is the only reason,
# there is no technical problem with PDF import on iOS, and it stays enabled on all other platforms.
